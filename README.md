# Home Inventory

Ứng dụng quản lý tài sản trong nhà, giúp theo dõi các thiết bị, đồ đạc, giá trị, vị trí lưu trữ và thông tin bảo hành một cách trực quan và dễ dàng.

## Tính năng
- Dashboard thống kê tổng số lượng và tổng giá trị tài sản.
- CRUD quản lý chi tiết tài sản (tên, danh mục, vị trí, giá trị, ngày mua, hạn bảo hành, hình ảnh).
- Tìm kiếm và lọc theo vị trí, trạng thái bảo hành.
